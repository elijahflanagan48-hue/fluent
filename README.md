# fluent.

Интерактивный прототип личного кабинета преподавателя английского языка и его учеников.

## Что уже работает

- переключение между кабинетами преподавателя и ученика;
- обзор дня, баланс занятий и ближайшее расписание;
- недельный календарь;
- карточки учеников и остатки занятий;
- история оплат;
- доска домашних заданий;
- библиотека материалов;
- аналитика загрузки и дохода;
- сообщения и быстрый поиск `⌘ K`;
- формы добавления урока, ученика, оплаты и задания;
- адаптивная версия для телефона.

Демонстрационные данные хранятся в браузере. Для реального запуска следующим этапом нужно подключить авторизацию, базу данных и файловое хранилище.

## Локальный запуск

Проект не требует сборки. Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер в этой папке.

## GitHub Pages

1. Создайте репозиторий и загрузите в него файлы этой папки.
2. В настройках репозитория откройте **Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

После сохранения GitHub опубликует сайт по адресу вида `https://username.github.io/repository/`.

## Следующий этап

Для полноценного продукта стоит добавить:

- защищённый вход и роли преподавателя/ученика;
- базу учеников, уроков, оплат и заданий;
- напоминания о занятиях и оплатах;
- загрузку файлов и голосовых сообщений;
- интеграцию с видеосвязью и календарями;
- онлайн-оплату пакетов занятий;
- резервное копирование и экспорт данных.
